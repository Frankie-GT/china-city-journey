关于《中国城市之旅》

《中国城市之旅》 是一套探索中国地理空间与人文历史风物的交互式数字化地图志。

数据与技术体系：

  • 地理边界源：基于国家民政部与《AreaCity》全国三级（省、市、县）标准行政区划多边形数据。
  • 视觉风格：复刻典雅实体印刷挂图《县域地图.jpeg》审美，采用暖米色宣纸质感底色与低饱和莫兰迪行政分色体系。
  • 架构特性：纯静态零构建 Web 架构，支持省级、地级、县级无级平滑缩放与按需异步加载。

本项目代码支持直接部署至 GitHub Pages / Gitee Pages 托管平台。
