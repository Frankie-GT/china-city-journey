# 中国城市之旅 (China City Journey)

> **山川行迹 · 县域风物志**  
> 优雅还原中国经典出版挂图质感的「省-市-县」三级行政区划交互地图与深度人文风物阅读系统。

---

## 🌟 核心特性

- 🎨 **出版物级典雅视觉**：深度还原经典印刷挂图的温暖宣纸底色（`#F6F3EB`）、传统莫兰迪低饱和行政分色、三级边界层级规范（省界粗实线 / 市界中细实线 / 县界精致虚线）及典雅宋体文字光晕，告别现代电子地图的冷硬色调。
- 🔍 **三级无缝平滑下钻**：
  - **全国视图**：覆盖全国 34 个省级行政区及规范版南海诸岛附图，首屏矢量数据仅约 400KB，秒开渲染。
  - **地级市视图**：点击省份下钻，仅标注地级市，界面干净明晰，同步加载邻省接壤城市地理多边形。
  - **区县级视图**：下钻至地级市后展示区县边界与注记，支持跨市县级接壤邻界联动。
- 📖 **图文双向联动风物志**：
  - 点击收录城市，侧边抽屉徐徐展开该城市的历史地理深度长文。
  - 点击具体区县，文章自动平滑滚动定位至对应县域章节并附带优雅呼吸光晕。
  - 暂未撰写文稿的城市，自动呈现民政部标准区划编码、拼音及下辖区县速查卡片。
- 📱 **极致移动端自适应**：
  - 手机端采用轻量底部抽屉（Bottom Sheet）。
  - 默认保持折叠收起状态，留出纯粹的读图视野；仅在点击有文稿收录的区县时才智能弹出，掌上浏览极为舒适。
- ⚡ **纯静态极简架构**：基于原生 HTML5 + CSS3 + ES6 + Leaflet 构建，无需打包编译，依托轻量分级切片实现丝滑浏览。
